# PrayogX reels - public media for Instagram publishing

Each folder holds one approved PrayogX reel (`reel.mp4`) and its cover (`thumbnail.jpg`), served by GitHub Pages so
that Instagram's API can download it (`video_url`). The PrayogX publisher checks that the hosted file is
byte-identical to the reel the owner approved before it publishes. The simulations live at https://prayogx.co.in.
